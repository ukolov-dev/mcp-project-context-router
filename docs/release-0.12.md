# Обновление до 0.12.0

Релиз основан на 0.11.0 и сохраняет его клиентские интеграции, Tree docs,
экспериментальный FTS5 и исключения устаревших типов записей.

- `explain`, `affected`, `path`: статические связи TS/JS с файлами и строками.
- `init`: `.project-context/ROUTER.md` и обновляемый блок AGENTS.md. Пользовательский
  текст снаружи блока и существующий плейбук сохраняются.
- Кэши текста/хешей живут в пределах операции; проверка реальной цели и границ
  репозитория остаётся при каждом обращении.
- MCP выполняет инструменты в одном worker. Через пять секунд ожидания возможен
  `RUNNING`; заберите результат через `get_operation_result`. Не повторяйте запрос
  записи: он уже может выполняться. Результаты теряются при перезапуске/вытеснении.
- Doctor/lint по умолчанию компактны. CLI: `--full`. MCP: `detail: full`,
  `fullResultUri` или polling с `detail: full` для того же полного снимка.

После установки выполните `project-context index` и перезапустите MCP-соединение.
Индекс одноразовый: смена схемы также автоматически инициирует его перестройку.
Нативная Windows-квалификация не выполнена; CLI по-прежнему синхронный.

Подробности: [MCP](mcp-operations.md), [символы](symbol-graph.md).
