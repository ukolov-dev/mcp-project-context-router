# Обновление до 0.12.1

Патч к 0.12.0 исправляет семь приоритетных дефектов из аудита:

1. ID контракта задачи проверяется до работы с файлами; небезопасные пути и
   переходы через символические ссылки отклоняются.
2. Неверный, нулевой или небезопасно большой срок `archive stale --older-than`
   отклоняется до перемещения записей. Корректный формат: `90d`.
3. `restore` отказывает при существующей active-записи и сохраняет обе версии.
4. Аналитические excerpts маскируют обнаруженные секреты общим механизмом.
5. Новые source drafts получают уникальные ID записей и создаются без перезаписи;
   логический `source_id` и ранее созданные записи сохраняются.
6. Таймаут Portal охватывает получение заголовков и полное чтение тела ответа.
7. Точный Portal snapshot принимается только при совпадении ID с запросом.

Версии зависимостей сохранены. Автоматической миграции или очистки памяти нет.
После установки перезапустите MCP-соединение, чтобы оно загрузило новый код.

Подробности базового релиза: [0.12.0](release-0.12.md).
