# Обновление до 0.12.2

Патч упрощает код и функциональность по пунктам 8–12 аудита.

- Удалён неиспользуемый синхронный `resolvePortalCredential`. Прямые импорты
  замените на `await resolvePortalAccessToken(...)`; штатные CLI/MCP-вызовы уже
  используют этот путь. Bearer credentials и обновление OAuth сохранены.
- Удалён `capture-commit`: команда возвращала успех без выполнения работы.
  Для обновления индекса используйте `project-context index --changed`.
- Четыре операции чтения Portal скрыты при неполной привязке проекта.
  `get_portal_sync_status` остаётся доступным. Настроенные проекты и профиль
  `full` сохраняют прежние инструменты.
- TS/JS-декларации для discovery и графа берутся из одного Compiler API-разбора.
  Комментарии и строки больше не создают фиктивные функции. Сохранены метаданные
  и ленивая загрузка TypeScript; индекс обновится по новой версии discovery.
- `export:standalone` сохраняется и копирует необходимые исходники сайта и
  скриптов; устаревшие фильтры и повторные преобразования удалены. Экспорт
  проверяется исполнением команд в полученной копии. `search:eval --engines current`
  работает и без FTS5, включая минимальную Node.js22.13.

`simple-git` и старый генератор refactor drafts были удалены до этого патча.
Версии зависимостей и существующая проектная память сохранены.

После обновления перезапустите MCP-соединение. Профиль `full` оставляет полный
набор инструментов для клиентов, которым нужен фиксированный список.
