# TASK-20260812-230639-001: Add tested installation guides for Codex and OpenCode

## Goal

Add tested installation and MCP client configuration guides for Codex and OpenCode, link them from README, preserve package boundaries, and publish the verified change to GitHub.

## Scope

- Document installation from the renamed GitHub repository.
- Provide project-scoped Codex configuration for desktop, CLI, and IDE.
- Provide separate OpenCode stable and V2 configurations.
- Ship copy-ready templates and test that each template launches the core MCP surface from a consumer repository.
- Include the guides and templates in standalone exports and package checks.

## Out Of Scope

- Publishing the package to the npm registry.
- Changing runtime tool behavior or MCP APIs.
- Adding clients beyond Codex and OpenCode.
- Adding credentials or absolute workstation paths.

## Acceptance Criteria

- README links to dedicated Codex and OpenCode guides.
- Client templates match their current official configuration schemas.
- Each template starts the installed MCP launcher in a temporary consumer repository and exposes the core profile.
- Build, tests, package checks, context lint, doctor, and GitHub CI pass.

Нет.

## Risks

- OpenCode stable and V2 schemas are incompatible and must not be mixed.
- Relative working directories must resolve to the consumer repository.
- GitHub installation requires npm lifecycle scripts to compile the package.
