# TASK-20260928-135011-001: Add persistent research-to-backlog workflow through MCP and CLI

## Goal

Add persistent research-to-backlog workflow through MCP and CLI

## Scope

- Separate research records with append-only discussion stages, statuses, open questions and conclusions
- Linked, retry-safe draft backlog handoff using existing backlog workflow
- Planning MCP profile, CLI parity, portable Codex skill and documentation

## Out Of Scope

- Automatic chat transcript collection
- UI application
- Automatic implementation of research ideas
- Release publication

## Acceptance Criteria

- Research history survives reopening and status changes without replacing earlier entries
- List and detail expose status, current questions, conclusion and linked backlog records
- Backlog handoff requires a ready conclusion and retries do not duplicate tasks
- Research is indexed and linted as a separate record type
- MCP planning profile and CLI support the workflow with regression coverage

Нет.

## Risks

- Concurrent writers and repeated handoffs must not lose history or create duplicates
